## Admin Panel Features

### Tab 1: Content
Edit all website text and headlines:
- Hero section headline and subheadline
- About section content
- Services descriptions
- Contact information
- And more...

**How to use:**
1. Find the section you want to edit
2. Click on the text field
3. Make your changes
4. Click "Save Changes" (blue button at top right)
5. Changes appear instantly on the website

### Tab 2: Images
Manage all website images:
- Add new images from external URLs (Pexels, Unsplash, etc.)
- View all images by section
- Delete images you no longer need

**To add an image:**
1. Fill in the "Add New Image" form
2. Select the section (hero, about, services, car-hire, contact)
3. Enter image name (e.g., "Hero Background")
4. Paste image URL from Pexels.com or similar
5. Add descriptive alt text for accessibility
6. Click "Add Image"

**To delete an image:**
1. Find it in the gallery
2. Click "Delete" button
3. Confirm deletion

### Tab 3: Settings
View your admin account information and helpful tips.

## Technical Details

The admin panel is built with:
- React + TypeScript
- Tailwind CSS for styling
- Supabase for database and real-time updates
- React Router for navigation

All changes made in the admin panel are:
- Stored in the Supabase database
- Instantly reflected on the website
- Accessible to all users in real-time
- Persistent across browser sessions
