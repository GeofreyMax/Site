# ICR Investment Traders - Admin Panel Documentation

## Welcome!

Your ICR Investment Traders website now has a professional admin panel for managing all content and images. No coding knowledge required!

## Getting Started Quickly

### Step 1: Login to Admin Panel
1. Open your browser
2. Go to: `http://localhost:5173/admin/login`
3. Enter these credentials:
   - **Username**: `admin`
   - **Password**: `1122`
4. Click "Sign In to Admin Panel"

### Step 2: Make Your First Edit
1. You'll see the Admin Dashboard
2. Click on the "Content" tab
3. Find "hero" section and click on the headline field
4. Edit the text
5. Click "Save Changes" (blue button at top right)
6. Go back to the website and see your changes!

1. Click on any text field
2. Make your changes
3. Click "Save Changes" button
4. Changes appear instantly on the website

---

### 🖼️ Images Tab
Manage all images used on your website.

**What you can do:**
- Add new images
- View all images by section
- Delete images

**To add an image:**
1. Scroll to "Add New Image" section
2. Fill in the form:
   - **Section**: Choose from dropdown (hero, about, services, car-hire, contact)
   - **Image Name**: Describe the image (e.g., "Hero Background", "Team Photo")
   - **Image URL**: Paste link from Pexels, Unsplash, or similar
   - **Alt Text**: Describe the image (helps with accessibility and SEO)
3. Click "Add Image"
4. Image appears in gallery below

**To delete an image:**
1. Find the image in the gallery
2. Click the "Delete" button
3. Confirm deletion

**Note**: We don't store images on our server. We use URLs from free image websites. This keeps things simple and fast!

## How Changes Work

1. **You edit in admin panel** → Changes saved to database
2. **Database sends update signal** → Website gets notified in real-time
3. **Website refreshes content** → All visitors see new content
4. **No page reload needed** → Smooth, instant updates

## Troubleshooting

### Images not loading?
- Check the image URL - copy it again from Pexels/Unsplash
- Make sure it starts with `https://`
- Try a different image
- Check your internet connection

### Text not saving?
- Make sure you clicked "Save Changes" button
- Wait a moment for the save to complete
- Check if you're still logged in
- Try refreshing the page

### Can't login?
- Check username: should be `admin`
- Check password: should be `1122`
- Make sure Caps Lock is off
- Clear browser cache and try again
- Check internet connection

### Website showing old content?
- Press Ctrl+Shift+R (or Cmd+Shift+R on Mac) to force refresh
- Clear browser cache
- Try opening in an "Incognito" window
- Wait 30 seconds and refresh
