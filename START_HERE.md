## 🆘 Troubleshooting

### Can't login?
- Username: `admin` (lowercase)
- Password: `1122` (numbers)
- Check Caps Lock
- Clear browser cache

### Images not loading?
- Check image URL is correct
- Use https:// URLs
- Try different image
- Check internet connection

### Changes not saving?
- Click "Save Changes" button
- Check you're still logged in
- Try refreshing page
- Wait a moment for save

### Website showing old content?
- Press Ctrl+Shift+R (Cmd+Shift+R on Mac)
- Clear browser cache
- Open in Incognito/Private window
